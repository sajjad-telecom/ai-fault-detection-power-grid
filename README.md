# AI-Based Fault Detection in Electrical Distribution Networks ⚡

## Project Overview

This project focuses on developing a Machine Learning-based approach for detecting and classifying faults in electrical distribution networks.

The main objective is to analyze electrical measurements such as voltage and current to identify abnormal operating conditions.

## Research Objectives

- Detection of normal and faulty operating conditions.
- Identification of short-circuit faults.
- Detection of ground faults.
- Identification of overload conditions.
- Exploring Machine Learning techniques for intelligent power system monitoring.

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Project Roadmap

1. Understanding electrical fault types.
2. Creating a simulated electrical dataset.
3. Data preprocessing and analysis.
4. Developing Machine Learning models.
5. Evaluating model performance.
6. Improving fault classification accuracy.
